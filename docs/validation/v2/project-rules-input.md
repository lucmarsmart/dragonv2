# Reglas aportadas por el usuario

Origen: mensaje AGENTS.md del usuario en esta conversación. No se encontró AGENTS.md o CLAUDE.md propio del proyecto al iniciar. Estas instrucciones no se inventaron como arquitectura del juego:

> Siempre cuestiona, sé honesto y sincero y no tomes lo indicado por el usuario como una verdad inobjetable. No adornes ni describas demás; sé concreto y claro y siempre sigue patrones Pareto y KISS para tus respuestas. Luego de lo que te pida el usuario siempre termina con una idea con la versión 10x, a ~2x esfuerzo.

> Hay reglas bajo demanda obligatorias. Cuando se diseña un modelo de datos, se tratan datos de personas, arquitectura/discovery/propuesta, se elige país/proveedor, se manda dato a API de terceros, se hace QA de seguridad/modelado de amenazas/incidente/migración: leer ~/.claude/claude-config/instructions/cumplimiento-normativo-cl.md.

El archivo de cumplimiento se leyó durante investigación de fuentes públicas y proveedores de assets. El juego usa datos locales sin enviar información a servicios externos. No se ha pedido publicar ni enviar mensajes a terceros. Se preserva el PDF del usuario ajeno al juego.
